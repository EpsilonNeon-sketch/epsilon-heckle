Welcome to Epsilon Heckle Studio

Epsilon Heckle Studio is a premium, browser-based 3D game creation tool. Build entire game worlds using primitives, pre-built assets, custom lighting, and terrain — then jump into Play Mode to test your creation in real time. No downloads. No installs. Just open and create.

14 Primitives

Cubes, spheres, cylinders, cones, tori, capsules, platonic solids, stairs, terrain hills and more.

50+ Assets

Characters, vehicles, weapons, buildings, nature props, and tools — ready to place instantly.

5 Light Types

Point, Spot, Directional, Hemisphere, and Rect Area lights for full scene illumination control.

Play Mode

First-person play testing with WASD movement, mouse look, jumping, running, and mobile joystick.

Export Anywhere

Save scenes as JSON, export individual objects as GLTF, or take high-res screenshots.

Procedural Terrain

Generate random terrain landscapes with adjustable size and height for open-world environments.

First time here? Jump straight to the Quick Start section — you'll have a playable scene in under 2 minutes.

Quick Start

Build your first playable game scene in 5 steps.

  1. 1

    Open the Studio

    Launch Epsilon Heckle Studio in your browser. A new empty scene loads automatically with a grid floor and default lighting.

  2. 2

    Add a Ground Plane

    Go to the Shapes tab in the left panel → click Plane. Select it and scale it up using the Scale tool (R key) to create a large floor.

  3. 3

    Place Some Objects

    Add cubes, spheres, or assets from the Assets tab. Use W (Move), E (Rotate), R (Scale) to arrange them. Click objects in the viewport to select, or use the Scene hierarchy list.

  4. 4

    Set the Atmosphere

    Switch to the World tab. Adjust sky color, ambient light, and sun angle. Enable fog for depth. Optionally switch the ground to Terrain for a procedural landscape.

  5. 5

    Hit Play

    Click the red Play button in the top bar. You'll drop into first-person mode. Use WASD to walk, mouse to look around, Space to jump, and Shift to run. Press the Stop button or Esc to return to editing.

Save before playing! Play Mode is a test simulation. Always save your scene (Ctrl+S) before entering Play Mode so you don't lose work if the browser refreshes.

Interface Tour

The studio is divided into 5 main areas.

Top Bar

Brand logo, New/Save/Load/Export buttons, Settings, Help, and the Play button. The central hub for file operations.

Left Panel

4 tabs: Shapes (primitives & lights), Assets (library & import), Scene (hierarchy), World (environment settings).

The 3D canvas where your scene renders. Orbit with right-click drag, zoom with scroll, select by clicking. Toolbar at top for transform modes.

Status Bar

Current mode (Edit/Play), object count, FPS counter, selection info, and version number.

Mobile users: On screens under 900px wide, the left and right panels are hidden by default. Use the Package and Sliders buttons in the top bar to toggle them as overlays.

Creating a Scene

A scene is the container for everything in your game world — objects, lights, environment settings, and terrain.

  1. 1

    New Scene

    Click New in the top bar or use Ctrl+N. This clears the current scene and resets to a fresh empty world with default grid and lighting.

  2. 2

    Build the World

    Add ground, structures, decorations, and lights. Arrange them using the transform tools. Every object you add appears in the Scene hierarchy tab.

  3. 3

    Configure the Environment

    Use the World tab to set sky color, ambient/sun lighting, fog, and ground type. This defines the overall mood of your scene.

  4. 4

    Save Your Work

    Click Save or press Ctrl+S. The scene is stored in your browser's local storage. Give it a descriptive name when prompted.

Unsaved changes are lost on refresh. The studio does not auto-save. Make a habit of saving frequently, especially before Play Mode or closing the tab.
Scene organization tip: Name your objects clearly in the Inspector. Use the Scene hierarchy to reorder and manage complexity. Click the trash icon next to the "Scene Hierarchy" title to clear all objects at once.

Import Custom Models

Click "Import GLTF / GLB" in the Assets tab to load your own 3D models from file. Supported formats:

SettingOptionsDescription

Ground Types Explained

Flat Plane: A simple infinite ground plane. Best for indoor scenes, platformers, or when you want manual control of the floor.

Terrain (Procedural): A randomly generated heightmap landscape. Adjustable size (50–500 units) and height scale (0–50). Click "Regenerate" to create a new random terrain. Ideal for outdoor and open-world games.

None: No ground at all. Objects float in space. Useful for space scenes or when you have a custom floor object.

Terrain regeneration is destructive. Clicking "Regenerate" creates a completely new random terrain. Any manually placed objects on the old terrain may end up floating or clipping.

Lighting

Good lighting transforms a flat scene into a believable world. The studio provides 5 light types.

Add lights from the Shapes tab under the "Lights" section:

LightBehaviorBest For
PointRadiates equally in all directions from a pointLamps, fire, overhead lights, torches
SpotCone of light in one directionFlashlights, stage lights, car headlights
DirectionalParallel rays from infinity (like the sun)Sunlight, moonlight
HemisphereSky color from above, ground color from belowAmbient outdoor fill light
Rect AreaLight from a rectangular area (soft shadows)Windows, TV screens, soft panels
Lighting tips:
  • Start with the environment Sun + Ambient, then add local lights for detail.
  • Use warm colors (orange, yellow) for indoor/cozy and cool colors (blue, white) for outdoor/tech.
  • Too many real-time shadow-casting lights hurts performance. Limit shadow-casters to 2–3 key lights.
  • The Street Lamp asset includes a built-in Point Light — use it for automatic light placement.

Asset Library Deep Dive

The asset library combines GLTF models loaded from CDN with procedurally generated objects.

GLTF Models

These are real 3D models loaded from the Three.js and Khronos Group sample model repositories. They include:

  • Animated characters (Soldier, XBot, Robot Expressive)
  • Animals with animations (Parrot, Horse, Flamingo, Fox)
  • Detailed static models (Antique Camera, Lantern, Sponza, Buggy, Duck)
Loading time: GLTF assets are fetched from a CDN on first use. You may see a brief loading spinner. Once loaded, they're cached for the session. An internet connection is required for GLTF assets.

Procedural Assets

These are built entirely from code — no network request needed. They load instantly and include vehicles (Car, Truck), weapons (Sword, Gun, Axe, Bow, Shield), structures (House, Building, Tower, Wall, Bridge, Fence), and nature (Tree, Crystal, Lamp). They're simpler than GLTF models but perfect for gameplay prototypes.

Importing Your Own Models

  1. 1

    Prepare Your Model

    Export from Blender, Maya, or any 3D tool as .glb (recommended) or .gltf. Keep file size under 10 MB for best performance.

  2. 2

    Click Import

    In the Assets tab, click "Import GLTF / GLB". A file picker opens. Select your model file.

  3. 3

    Model Appears in Scene

    The imported model is placed at the world origin. It also appears in the Assets grid under a "Custom" category for reuse.

Import limitations: Only GLTF and GLB formats are supported. FBX, OBJ, and other formats must be converted first (use Blender's export feature). Very high-poly models may cause performance issues.

Play Mode

Play Mode lets you experience your scene as a first-person player. It's the fastest way to test scale, layout, and "feel" of your game world.

Entering Play Mode

  • Click the red Play button in the top bar
  • A "Play Mode" indicator appears in the top-left corner
  • The viewport changes to first-person camera
  • On desktop: the mouse is captured for looking — click the viewport if needed
  • On mobile: a virtual joystick and look pad appear

Exiting Play Mode

  • Click the Stop button (top-right during Play)
  • Press Esc to release mouse, then click Stop

Physics & Collision

Play Mode includes basic character physics:

  • Gravity pulls the character down when not on a surface
  • Jump launches the character upward (Space)
  • Ground collision prevents falling through the floor/terrain
  • Running increases movement speed (Shift)
Play Mode limitations:
  • There is no object-to-object collision — the player can walk through placed objects.
  • There is no game logic, scoring, or AI — Play Mode is a walk-through simulator only.
  • Object animations (if present in GLTF models) play automatically but cannot be controlled.
  • Changes made during Play Mode do not persist when you stop.
Play Mode is a preview, not a final game. To create a fully playable game with logic, collision, scoring, and UI, you'll need to export your scene and build the game logic in a separate engine or codebase. The studio excels at world building and visual prototyping.

Save & Load

Saving

  • Click Save or press Ctrl+S
  • A prompt asks for a scene name (default: "Untitled")
  • The scene is serialized to JSON and stored in the browser's localStorage
  • Saving overwrites any previously saved scene with the same name

Loading

  • Click Load to open the load modal
  • A list of all saved scenes appears with timestamps
  • Click a scene to load it — this replaces the current scene
  • Each saved scene has a delete button (trash icon)
localStorage limits: Browser localStorage typically holds 5–10 MB. Very large scenes with many objects may exceed this limit. If saving fails, try reducing object count or clearing old saved scenes.
Clearing browser data deletes saves. Saved scenes are local to this browser and device. Clearing cookies/cache/site data will erase all saved scenes. Use Export to back up important work as downloadable files.

Troubleshooting

Scene appears black / objects are invisible

This usually means lighting is too low or the camera is inside an object.

  • Increase Ambient value in the World tab (try 0.6+)
  • Increase Sun Intensity (try 1.5+)
  • Add a Point Light near your objects
  • Press F to focus on a selected object and move the camera to it
  • Click Reset Camera (home icon) in the viewport toolbar
GLTF asset fails to load

GLTF assets require an internet connection to download from CDN. If loading fails:

  • Check your internet connection
  • Try refreshing the page — CDN may have had a temporary issue
  • Use procedural assets instead — they work offline
  • Very large GLTF files may time out; try a simpler model
Performance is slow / low FPS

Try these steps to improve performance:

  • Reduce the number of objects in the scene
  • Limit shadow-casting lights to 2–3
  • Disable fog if not needed
  • Use procedural assets instead of heavy GLTF models
  • On mobile, keep scenes under 50 objects
  • Close other browser tabs to free GPU memory
Can't select objects by clicking

Object selection uses raycasting from the camera through the click point.

  • Make sure you're clicking on the object's visible surface, not empty space
  • Very small or far-away objects can be hard to click — use the Scene hierarchy list instead
  • Objects behind other objects may be occluded — orbit the camera to get a clear angle
Save fails or "storage full" error

localStorage has a ~5–10 MB limit per origin.

  • Delete old saved scenes in the Load modal
  • Export important scenes as JSON files first, then delete them from localStorage
  • Reduce scene complexity (fewer objects)
Play Mode: character falls through floor

The character collider checks for ground below it. If you fall through:

  • Make sure a ground plane or terrain is enabled in the World tab
  • The spawn point may be below the ground — stop Play Mode and try again
  • Very steep terrain angles may not register as "ground"
Imported GLTF model looks wrong

Common issues with imported models:

  • Missing textures: GLTF text format (.gltf) may reference external files that can't be loaded. Use .glb (binary) instead — it embeds everything.
  • Wrong scale: Some models export in centimeters. Use the Scale tool to resize.
  • Wrong orientation: Some models face -Z instead of +Z. Rotate to fix.
  • Unsupported features: The studio uses Three.js GLTFLoader — any feature it supports will work.

Glossary

Asset
A pre-built 3D model (GLTF or procedural) that can be placed into a scene.
GLTF / GLB
GL Transmission Format — the standard 3D file format for web and real-time. GLB is the binary (single-file) variant.
Gizmo
The visual handle (arrows, rings, boxes) that appears on a selected object for translating, rotating, or scaling.
Inspector
The right panel showing editable properties of the currently selected object.
Metalness
A PBR material property: 0 = dielectric/plastic, 1 = fully metallic/reflective.
PBR
Physically Based Rendering — a shading model that simulates real-world light interaction for realistic materials.
Primitive
A basic 3D shape (cube, sphere, cylinder, etc.) generated from geometry parameters.
Procedural
Generated by code rather than loaded from a file. Procedural assets load instantly and work offline.
Roughness
A PBR material property: 0 = perfectly smooth/mirror, 1 = fully rough/matte.
Scene
The complete game world — all objects, lights, environment settings, and hierarchy.
Scene Hierarchy
The ordered list of all objects in the scene, shown in the Scene tab of the left panel.
Transform
The combination of Position, Rotation, and Scale that defines an object's placement in 3D space.
Viewport
The central 3D canvas where the scene is rendered and interacted with.
